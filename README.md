# CCF_Theme

코코포리아(ccfolia.com) 테마 커스터마이저 — Chrome 확장 프로그램

다크 테마로 고정된 ccfolia.com의 색상을 자유롭게 바꿀 수 있는 확장 프로그램. Chrome
웹스토어에는 등록되어 있지 않아, 아래 안내에 따라 코드를 내려받아 직접 설치해야 함.

## 설치 방법

> ⚠️ 반드시 **`main` 브랜치**에서 다운로드할 것. 저장소 페이지 좌측 상단 브랜치 선택 메뉴가
> `main`인지 먼저 확인. 그 외 브랜치는 개발 중인 코드라 불안정할 수 있음.

1. 저장소 페이지 우측 상단 초록색 **`<> Code`** 버튼 → **Download ZIP** 선택
2. 다운로드한 zip 파일 압축 해제 (`CCF_Theme-main` 폴더 생성됨)
3. Chrome 주소창에 `chrome://extensions` 입력
4. 우측 상단 **개발자 모드** 켜기
5. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 해제한 폴더 안의 **`ccfolia-theme`**
   폴더 선택 (최상위 폴더가 아니라 그 안의 `ccfolia-theme` 폴더를 선택해야 함)
6. 툴바에 아이콘이 뜨면 설치 완료

**업데이트**: 새 버전을 같은 방법으로 내려받아 기존 폴더를 덮어쓰고, `chrome://extensions`에서
새로고침(↻) 버튼 클릭. 열려 있던 ccfolia 탭도 새로고침.

## 사용법

1. https://ccfolia.com 방 입장
2. 툴바 아이콘 클릭 → 팝업 열기
3. 프리셋 선택 또는 색상 직접 조정 → 즉시 반영, 자동 저장

### 프리셋

팝업 상단에 프리셋 4개가 어두운 톤부터 밝은 톤 순서로 배치됨(기본 → 다크 → 화이트 → 세피아).
버튼마다 실제 배경색/글자색이 미리보기로 표시됨.

- **기본**: 원본 다크 테마 그대로 (확장을 끈 것과 동일)
- **다크**: 눈이 편하도록 대비를 조정한 다크 팔레트
- **화이트**: 밝은 톤 (기본값)
- **세피아**: [Solarized Light](https://ethanschoonover.com/solarized/) 배색 기반. 크림색
  배경에 부드러운 톤의 텍스트

프리셋 아래 색상 4가지(배경 / 기본 텍스트 / 보조 텍스트 / 강조색)를 스와치 또는 HEX 코드로
직접 조정 가능.

룸(보드) 배경과 캐릭터 발신자명·주사위 판정 색은 건드리지 않음 — 방 표지 사진이나 여러 명이
함께 보는 색상이라 원래 값을 그대로 유지.

### 커스텀 테마

색상 조정 후 "+ 새 테마 저장"으로 이름을 붙여 저장 가능. 여러 개 저장할 수 있고, 각 테마 옆
× 버튼으로 삭제 가능. 삭제 후 몇 초 안에 "실행취소"로 복구 가능.

### 내보내기 / 가져오기

"내보내기"로 현재 색상 조합을 JSON 코드로 복사, "가져오기"로 붙여넣으면 동일한 조합 적용.
테마를 다른 사람과 공유할 때 사용.

### 단축키

기본값 `Ctrl+Shift+U` — "기본"과 마지막으로 쓰던 테마를 토글. 다른 단축키와 겹치면
`chrome://extensions/shortcuts`에서 변경 가능.

버그 제보나 의견은 팝업 하단 링크 또는
[GitHub Issues](https://github.com/lime-0v0/CCF_Theme/issues) 이용.

## 폴더 구조

```
ccfolia-theme/
├── manifest.json        확장 프로그램 설정
├── theme.js              기본 테마 값 및 공용 유틸
├── content.js            테마 CSS 주입
├── background.js         단축키 처리
├── popup.html/.css/.js   팝업 UI
└── icons/                아이콘
```

## 참고

ccfolia 내부 구조상 일부 요소(HP 게이지 바 등)는 안정적인 CSS 클래스가 없어 임시방편으로
처리함. ccfolia 업데이트 시 해당 부분이 깨질 수 있으며, 발견 시 이슈로 제보 바람.
