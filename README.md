# CCF_Theme

코코포리아(ccfolia.com) 테마 커스터마이저 — Chrome 확장 프로그램 (Manifest V3)

다크 테마 고정인 ccfolia.com의 색상을 사용자가 원하는 대로 바꿀 수 있게 해줍니다.

## 폴더 구조

```
ccfolia-theme/
├── manifest.json   ← 확장 프로그램 설정 (MV3)
├── theme.js        ← 기본 테마 값 / 공용 유틸 (popup.js, content.js 공유)
├── content.js       ← 테마 CSS를 페이지에 주입
├── popup.html/.css/.js ← 툴바 아이콘 클릭 시 뜨는 색상 선택기 UI
└── README.md
```

## 진행 상황

1. ✅ CSS 주입 (헤더/다이얼로그/아이콘/입력창/보드 오버레이 텍스트 등)
2. ✅ 팝업 UI (색상 선택기)
3. ✅ `chrome.storage.local`에 사용자가 고른 색 저장/로드
4. ✅ content.js가 storage 값을 읽어 동적으로 CSS 적용 (`storage.onChanged`로 실시간 반영)

팝업 상단에 프리셋 4개가 어두운 톤부터 밝은 톤 순서로 있습니다(기본 → 다크 → 화이트 → 세피아).
각 버튼은 실제 배경색/글자색으로 미리보기가 되어 있어서 눌러보지 않아도 어떤 느낌인지 바로
보입니다. 그 아래 색상 4가지(헤더/입력창/사이드바/패널 배경(하나로 통일), 기본 텍스트, 보조
텍스트, 활성 탭/강조색(전송 버튼도 같이 씀))를 스와치 또는 HEX 코드 직접 입력으로 조정할 수
있습니다.

- **기본**: CSS를 아예 주입하지 않음 — ccfolia 원본 다크 테마 그대로(확장을 끈 것과 동일).
- **다크**: "기본"과 달리 CSS를 주입하는 다크 팔레트입니다. Material Design의 다크 테마
  가이드라인(표면색을 순검정이 아닌 `#121212` 근처로 둬서 헤일레이션/눈부심을 줄임)을 참고해
  대비를 다시 계산했습니다 — 배경 대비 기본 텍스트 14:1, 보조 텍스트 6.6:1, 강조색 6.2:1로
  전부 WCAG AA(4.5:1)를 넉넉히 통과합니다.
- **화이트**: 지금까지 만든 밝은 톤(기본값).
- **세피아**: [Solarized Light](https://ethanschoonover.com/solarized/) 배색 기반 — 크림색
  배경 + 채도를 낮춘 슬레이트 톤 텍스트로, 순백/순검정보다 눈이 편한 배색입니다.

룸(보드) 배경(씬 이미지가 없을 때 보이는 부분)은 의도적으로 색을 칠하지 않습니다 — 항상 방
표지 사진을 블러 처리한 배경 레이어가 깔려 있어서, 여기에 단색을 덮으면 그 사진을 가려버립니다.

캐릭터 발신자명 색과 주사위 판정 결과(BCDice) 색은 여러 명이 같은 화면을 보는 공유 데이터라
일부러 건드리지 않습니다 — ccfolia가 지정한 색을 그대로 씁니다.

색을 직접 조정한 뒤 "+ 새 테마 저장"을 누르면 이름을 물어보고, 그 조합이 프리셋 줄 아래 가로선
너머에 별도 버튼으로 추가됩니다 — 기본 제공 프리셋과 내가 만든 테마가 시각적으로 구분됩니다.
여러 개를 계속 추가할 수 있고, 각 버튼 오른쪽 위의 작은 × 를 누르면 그 테마만 삭제됩니다.

"내보내기" 버튼을 누르면 지금 색 조합이 한 줄 JSON으로 표시되고 클립보드에 복사됩니다(복사가
막혀 있으면 텍스트가 선택된 채로 나오니 직접 Ctrl+C 하면 됩니다). 이 코드를 다른 사람에게
공유하면, 그 사람은 "가져오기"를 눌러 붙여넣고 Enter만 누르면 똑같은 조합을 바로 적용할 수
있습니다. 붙여넣은 값은 알려진 색상 필드 + HEX 형식인지 검증한 뒤에만 반영됩니다.

## 설치 및 테스트 방법

1. `chrome://extensions` → 우측 상단 "개발자 모드" 켜기 → "압축해제된 확장 프로그램을 로드합니다" →
   `ccfolia-theme` 폴더 선택
2. https://ccfolia.com 방에 입장
3. 툴바의 확장 프로그램 아이콘을 클릭해 색상을 선택하면 즉시 반영됩니다.
4. `content.js`나 `manifest.json`을 수정한 경우엔 `chrome://extensions`에서 새로고침 버튼을 누르고,
   ccfolia 탭도 새로고침해야 반영됩니다. (색상 값 변경은 새로고침 없이 즉시 반영됩니다.)

버그를 발견했거나 의견이 있다면 팝업 하단의 "버그 제보 · 의견 남기기" 링크(또는
[GitHub Issues](https://github.com/lime-0v0/CCF_Theme/issues))로 남겨주세요.

## 기술적 배경

- ccfolia는 React + MUI(Material UI) + emotion 기반이며, 다크 테마가 하드코딩되어 있습니다.
- emotion이 생성하는 해시 클래스(`sc-xxxxx`, `css-xxxxx`)는 빌드마다 바뀔 수 있어 셀렉터로 사용하지
  않습니다. 대신 `Mui-` 접두사 클래스와 `data-testid` 속성 위주로 셀렉터를 잡습니다.
- 예외적으로 HP 게이지 바는 안정적인 Mui 클래스가 없어 해시 클래스(`.sc-kMGnbm`, `.sc-ksXhwP`)를
  직접 사용합니다. ccfolia 버전(현재 1.36.3) 업데이트 시 깨질 수 있습니다.
- 주사위 판정 결과(BCDice)처럼 사이트가 자체적으로 색을 입히는 요소는 `!important` 없이 낮은
  우선순위로만 기본값을 채워서, 사이트가 지정한 색(크리티컬/펌블 등)이 자연스럽게 이기도록 합니다.

## 검증된 영역

장면/마커/씬 텍스트/컷인 목록 패널, 설정(⚙️) 다이얼로그, 카드 뭉치(deck of cards) UI, 컨텍스트
메뉴 반투명 효과까지 실제 ccfolia 방에서 확인 완료 — 모두 정상적으로 테마가 적용됩니다.

## 라이선스 / 서드파티 고지

이 프로젝트는 [MIT License](LICENSE)로 배포됩니다.

순수 HTML/CSS/JavaScript로만 작성되어 있으며, `package.json`이나 외부 라이브러리·CDN 스크립트를
전혀 사용하지 않습니다 — 따라서 서드파티 라이선스 고지가 필요한 의존성이 없습니다. "세피아" 프리셋의
색 구성은 [Solarized](https://ethanschoonover.com/solarized/) (Ethan Schoonover, MIT License)의
색상값에서 영감을 받았을 뿐, 코드를 가져다 쓰지는 않습니다.
