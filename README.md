# 코코포리아 테마 테스트 (v0.1)

## 크롬에 로드하는 방법
1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`ccfolia-theme`)를 선택

## 테스트 방법
1. https://ccfolia.com 의 아무 방에 입장
2. 개발자도구(F12) → Console 탭에서
   `[코코포리아 테마 테스트] 스타일 주입 완료:` 로그가 찍히는지 확인
3. 아래 요소들의 색이 바뀌었는지 확인
   - 상단 헤더바 배경
   - 채팅 사이드바 배경
   - 채팅 메시지 이름/본문 텍스트
   - 선택된 탭(Main/Info/Other) 색
   - 메시지 입력창 배경
   - 전송 버튼 배경

## 안 바뀌는 부분이 있다면
`content.js`의 CSS 선택자가 실제 페이지 구조와 안 맞는 경우예요.
F12 → Elements 탭에서 해당 요소를 직접 클릭해 클래스명을 확인한 뒤 알려주시면
선택자를 수정해드릴게요.
